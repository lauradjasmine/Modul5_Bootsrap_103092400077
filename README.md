1. Bootstrap adalah framework front-end gratis dan open source berisi kumpulan CSS dan JavaScript siap pakai untuk membangun tampilan website yang responsif dan mobile-first. Framework ini awalnya dikembangkan oleh Mark Otto dan Jacob Thornton di Twitter pada tahun 2011. Kegunaan utamanya adalah mempermudah dan mempercepat pembuatan website, karena developer tidak perlu menulis kode CSS dari nol. Bootstrap menyediakan sistem grid untuk tata letak yang menyesuaikan ukuran layar desktop, tablet, maupun ponsel, serta komponen siap pakai seperti navbar, tombol, form, card, modal, dan carousel. Selain itu, Bootstrap menjaga konsistensi desain di seluruh halaman, kompatibel di berbagai browser, dan mudah dikustomisasi sesuai kebutuhan.
2. Ada beberapa cara untuk menggunakan Bootstrap pada project. Cara paling praktis adalah melalui CDN (Content Delivery Network), yaitu menambahkan link file CSS Bootstrap di bagian <head> dan script JavaScript-nya sebelum penutup </body> tanpa perlu mengunduh apa pun. Cara kedua adalah mengunduh file Bootstrap dari situs resminya, getbootstrap.com, menyimpannya di folder project, lalu menghubungkannya ke HTML secara lokal sehingga website tetap bisa berjalan tanpa koneksi internet. Cara ketiga adalah memasang melalui package manager seperti npm atau yarn dengan perintah npm install bootstrap, lalu mengimpornya ke dalam project. Cara ini umum digunakan pada project modern berbasis React, Vue, atau Laravel. Selain itu, Bootstrap juga dapat digunakan melalui source Sass jika developer ingin mengubah variabel seperti warna dan ukuran sebelum dikompilasi menjadi CSS.
3. Class grid adalah sistem tata letak Bootstrap berbasis flexbox yang membagi lebar halaman menjadi 12 kolom. Strukturnya terdiri dari .container sebagai pembungkus utama, .row sebagai baris, dan .col atau .col-* sebagai kolom di dalam baris tersebut. Dengan sistem ini, developer dapat mengatur berapa bagian dari 12 kolom yang ditempati sebuah elemen, misalnya .col-6 untuk setengah lebar atau .col-4 untuk sepertiga lebar. Breakpoint adalah batas lebar layar yang menentukan kapan tata letak berubah. Bootstrap memiliki enam breakpoint, yaitu extra small untuk layar di bawah 576px, sm mulai 576px, md mulai 768px, lg mulai 992px, xl mulai 1200px, dan xxl mulai 1400px. Kegunaan breakpoint adalah membuat tampilan yang berbeda di setiap ukuran perangkat. Misalnya, dengan class col-12 col-md-6 col-lg-4, konten tampil satu kolom per baris di ponsel, dua kolom di tablet, dan tiga kolom di desktop.
4. Bootstrap menyediakan banyak class siap pakai. Class .container digunakan sebagai pembungkus konten agar memiliki lebar responsif dan berada di tengah halaman. Class .btn yang dikombinasikan dengan .btn-primary, .btn-success, atau .btn-danger digunakan untuk membuat tombol bergaya dengan warna biru, hijau, atau merah. Class .navbar berfungsi membuat menu navigasi yang responsif dan dapat menyusut menjadi menu hamburger di layar kecil. Class .card digunakan untuk membuat kotak konten yang berisi gambar, judul, dan teks, misalnya untuk menampilkan produk. Class .text-center berfungsi meratakan teks ke tengah, sedangkan class spacing seperti .m-3 dan .p-3 digunakan untuk mengatur margin dan padding. Selain itu, ada .table untuk memberi gaya rapi pada tabel, .form-control untuk mempercantik input form, dan .img-fluid untuk membuat gambar responsif.
5. Agar foto atau gambar pada website dapat menyesuaikan ukuran layar perangkat, cara termudah di Bootstrap adalah menambahkan class .img-fluid pada tag <img>, contohnya <img src="foto.jpg" class="img-fluid" alt="Foto produk">. Class ini menerapkan properti max-width: 100% dan height: auto, sehingga gambar tidak akan melebihi lebar wadahnya dan proporsinya tetap terjaga ketika layar mengecil. Bootstrap juga menyediakan class pendukung seperti .img-thumbnail untuk memberi bingkai tipis dengan sudut membulat serta .rounded-circle untuk membuat gambar berbentuk lingkaran. Tanpa Bootstrap, hasil yang sama dapat dicapai dengan menuliskan CSS max-width: 100% dan height: auto pada elemen gambar. Untuk hasil yang lebih optimal, developer juga dapat menggunakan atribut srcset atau elemen <picture> agar browser memuat ukuran gambar yang berbeda sesuai layar, sehingga halaman lebih ringan saat dibuka di ponsel.
